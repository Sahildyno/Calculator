# 🧮 Calculator Web App

A simple and stylish calculator built using **HTML, CSS, and JavaScript**.  
This project demonstrates basic DOM manipulation, event handling, and responsive UI design.

---

## ✨ Features
- ➕➖✖️➗ Basic arithmetic operations
- 🎨 Modern **glassmorphism design**
- ⌨️ **Keyboard support** (numbers, operators, Enter, Backspace, Esc)
- 📱 Responsive layout (works on desktop & mobile)
- ⚡ Smooth hover & animation effects

---

## 🚀 Live Demo
🔗 (https://sahildyno.github.io/Calculator/)  

---

## 🛠️ Technologies Used
- **HTML5** – structure
- **CSS3** – styling (glassmorphism, gradients, shadows)
- **JavaScript (ES6)** – calculator logic & keyboard support
